# 麻辣先生スタンプカード

麻辣先生に行った記録を残す、自分用のスタンプカードです（お店の公式カードではありません）。

- 食べた回数スタンプ：来店1回で1個、10個で1枚満了
- 店舗ラリースタンプ：全10店舗のうち訪れた店に印
- スタンプは店舗からおよそ200m以内にいるときだけ、当日分として押せます（1店舗1日1回）
- 記録は開いた端末のブラウザ（localStorage）に保存されます

## 公開方法（AWS Amplify Hosting + Basic認証）

1. AWSコンソールで Amplify を開き、新しいアプリを作成して「GitHub」を選ぶ
2. GitHubの認可画面でリポジトリ `samples` へのアクセスを許可し、ブランチ `mala-stamp` を選ぶ
3. ビルド設定はリポジトリの `amplify.yml` がそのまま使われる（ビルドなしで `index.html` を配信）
4. デプロイ後、アプリの「ホスティング」→「アクセスコントロール」で `mala-stamp` ブランチを
   「制限付き - パスワードが必要」にし、ユーザー名とパスワードを設定する

パスワードはAWS側にだけ設定し、このリポジトリには書かないでください。
位置情報はHTTPSでのみ動きます（Amplifyの配信URLはHTTPSです）。
